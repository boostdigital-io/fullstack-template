# 0026. Editorconfiguratie voor Zed

Status: Aanvaard (2026-11-04)

## Context

Wat je in de editor ziet, moet gelijk zijn aan wat CI controleert. Zed is de editor die we gebruiken.

## Besluit

- `.zed/settings.json` staat in de repo.
- Biome uit `node_modules` is formatter en linter, met format-on-save, fixes en gesorteerde imports.
- De TypeScript-server is `effect-tsgo` ([ADR 0031](0031-typescript-7-effect-tsgo.md)).
- `repos/` is verborgen in Zed en uitgesloten van auto-imports.

## Gevolgen

- Andere editors worden niet ondersteund.
- Claude leest `repos/` met zijn eigen tools; een mens opent de map alleen via een pad.
